The tests swap the models for scripted ones, so they make no API calls; the screenshots on this page are from real calls. The backend tests were run in the development folder and are not included in this repository.

Found by this check, and fixed

  • Off-topic message could end in an error. Right after a blocked message, “Can you do my statistics homework?” made Dan send the Scout out for “Yale apparel” again and again until the 8-request limit, so the shopper saw “Sorry, that one tripped me up.” The prompt now tells Dan to answer off-topic requests without tools and to ask the Scout once per message, and agent.MAX_SCOUT_TRIPS caps Scout trips at 2 per message, with a regression test. The same request then passed 4 out of 4 times (check 18).
  • Small polish: the live view said “1 pieces that pair with…” (now singular when it should be), and the phone menu was too see-through over the dark hero (now nearly opaque).

How the screenshots were taken

On 2026-10-05, headless Chrome was driven over the DevTools protocol against the running site: it clicked, typed and waited like a shopper, then captured each state at 1440 × 900 (1.5× pixel density) or 390 × 844 for the phone views. The three animated recordings are short screen captures of the same session. Database values were read with sqlite3 data/campus_customs.db at the same time. Accounts used: the seed user (test@campuscustoms.yale.edu), a new one created in check 11 (morgan.signup@campuscustoms.test), and morgan.appcheck@campuscustoms.test, created the same way in the first run and used in checks 14, 15 and 20. Their passwords are not included in this repository.
